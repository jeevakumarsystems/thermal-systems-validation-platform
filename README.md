# thermal-systems-validation-platform

An experimentally validated, lump-parameter thermal model for sealed electronic enclosures operated under constrained cooling conditions.


## Objective

To design, construct, instrument, and validate a predictive thermal resistance network capable of modeling steady-state and transient behavior within +- 3-4 C.
## System Overview

The system contains:
- 6 calibrated NTC sensors
- 3-level controlled resistive heating (5W / 10W / 15W)
- Sealed ABS enclosure with aluminum conduction plate
- 48-run structured experimental matrix
- 10,000+ logged data points

## Modeling Approach
- Lumped capacitance node network
- Conduction, convection, and radiation components
- Explicit uncertainty propagation
- Stability-detection based steady-state criteria
